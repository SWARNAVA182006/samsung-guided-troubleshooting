================================================================================
DATA FLOW & EXECUTION PIPELINE
================================================================================
1. User enters natural language complaint on React Frontend.
2. Fastify Node Backend checks in-memory response cache. If hit, returns in <10ms.
3. If miss, request is proxied to Python AI Gateway.
4. AI Gateway resolves SIIS article from data/siis_responses.json via TF-IDF if unprovided.
5. Grounded Extractor parses article into logical action groups & repair steps.
6. Deeplink Retriever queries 578-entry catalog to attach actionable & validation URIs.
7. Validator verifies 100% URI catalog membership & strips external URL leaks.
8. Validated ContextDeeplinkResponse returned to Frontend for interactive rendering.
